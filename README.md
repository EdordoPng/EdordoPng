## Selected Work

### AI / Reasoning

- **[Advanced Network Science](https://edordopng.github.io/projects/network-science)**  
  Complex-system analysis using Graph Theory, from terrorist-cell disruption to scientific collaboration networks.

- **[Reverse Planning & Epistemic Reasoning](https://edordopng.github.io/projects/cannolo-planning)**  
  Comparative work on PDDL, ASP, Eclingo and epistemic planning for universally reversible actions.

- **[Conformant Elevator Planning](https://edordopng.github.io/projects/conformant-elevator)**  
  Automated planning under incomplete knowledge using Answer Set Programming.

### Cybersecurity

- **[Differential Power Analysis](https://edordopng.github.io/projects/dpa-analysis)**  
  Side-channel attack implementation against AES-128 using power-analysis distinguishers.

- **[Deep Learning for SCA Profiling](https://edordopng.github.io/projects/profiling-dl)**  
  Profiling attacks on ASCAD using MLP and CNN architectures.

- **[Secure MPC with Garbled Circuits](https://edordopng.github.io/projects/multi-party-computation)**  
  Yao's Garbled Circuits implementation for privacy-preserving computation.

- **[AES Encryption from Scratch](https://edordopng.github.io/projects/aes-implementation)**  
  Full Python implementation of AES including finite-field arithmetic and dynamic S-Box generation.
